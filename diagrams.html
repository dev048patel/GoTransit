Commuter Use Cases

UC1Sign Up Create account with email, password, full name, optional mobile. Includes password strength check and mobile number formatting. —Supabase Auth
UC2Log In Authenticate with email or mobile number + password. Mobile numbers are resolved to emails via RPC. Account status is checked (rejects suspended/deleted). «include» Validate Credentials
«include» Verify Authentication		 Supabase Auth
UC3View Live Bus Tracking See real-time bus positions on the map with color-coded markers and heading indicators. Starts automatically when the map loads. «include» Poll Bus Positions (1.5s)
«include» Cache Bus Data (miss-count)		 TransitLive API
UC4Plan a Trip Get up to 5 route suggestions (direct, transfer, walkable shortcut) between origin and destination. Ranked by live predictions, travel time, transfers and walking distance. «include» Search Destination
«include» Enrich with Live Predictions
«include» Track Analytics
«extend» Detect GPS Location		 Google Places API Browser Geolocation TransitLive API
UC5View Stop Departures Click a bus stop on the map to see a departure board with predicted arrival times for upcoming buses. —TransitLive API
UC6Search Places Search for destinations using Google Places Autocomplete. Map navigates to the selected place with a marker. —Google Places API
UC7Use "You Are Here" Auto-detect GPS location, display a pulsing blue dot on the map, continuously track user movement. —Browser Geolocation
UC8Manage Profile View and manage personal information, preferences and favourites. «include» Load Profile + Prefs + Favourites
«extend» Change Password
«extend» Edit Personal Info
«extend» Delete Account		 Supabase DB

Admin Use Cases

IDUse CaseDescriptionRelationshipsExternal Actors
UC10Log In (Admin) Same login flow as Commuter, but after authentication the system verifies role = 'admin' in the profiles table before granting admin panel access. «include» Verify Admin Role Supabase Auth
UC11View Dashboard View live metrics (registered user count, active routes, total interactions) with a weekly bar chart (places vs. directions) and daily pie chart (traffic by weekday). Auto-refreshes every 10 seconds. «include» Fetch Live Metrics (10s)
«include» Fetch Chart Data		 Supabase DB Feature API
UC12Manage Routes View all routes with status. Search/filter by name or number. «extend» Rename Route (optimistic UI + rollback)
«extend» Toggle Visibility (Active/Hidden)		 Backend Admin API
UC13Manage Users View all registered users with details (name, email, role, status, registration date, last active, online indicator). Search/filter users. Auto-refreshes every 15 seconds. «extend» Edit User Profile
«extend» Ban User (suspend)
«extend» Soft Delete User
«extend» Export Users CSV		 Supabase DB
UC14View Visitor Analytics View visitor sessions with device/browser distribution charts. Auto-refreshes every 30 seconds. «extend» Filter by Date Range
«extend» View Session Details		 Analytics API
